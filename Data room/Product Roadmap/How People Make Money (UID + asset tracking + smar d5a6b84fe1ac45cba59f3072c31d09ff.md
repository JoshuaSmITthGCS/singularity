# How People Make Money (UID + asset tracking + smart contracting)

Status: Planned
Priority: Medium
Category: New Feature, UI/UX
Team: Platform, Security
Project description: Monetization + attribution system that assigns a unique ID (UID) to every creator/client and permanently tags submitted code for tracking. Ensures original creators are identified and compensated when code is adapted and reused, with smart-contracting concepts to automate payouts and support a creator marketplace economy.
